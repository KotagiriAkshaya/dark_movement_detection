# Dark Room Movement Detection

## Project Overview
Dark Room Movement Detection is a real-time movement monitoring application designed to detect movement using a webcam, including in low-light or dark-room conditions.

The project provides a simple interface to monitor camera activity, simulate darkness, detect movement, and maintain detection history.

## Features
- Real-time webcam monitoring
- Movement detection
- Dark room simulation
- Detection alerts
- Detection history
- User-friendly web interface

## Technologies Used
- Python
- Flask
- HTML
- CSS
- JavaScript
- OpenCV
- YOLO (if used in the detection pipeline)

## How to Run the Project

1. Clone the repository:

   ```bash
   git clone https://github.com/KotagiriAkshaya/dark_movement_detection.git
   ```

2. Open the project folder:

   ```bash
   cd dark_movement_detection
   ```

3. Install the required dependencies:

   ```bash
   pip install -r requirements.txt
   ```

4. Run the application:

   ```bash
   python app.py
   ```

5. Open your browser and visit:

   ```text
   http://127.0.0.1:5000
   ```

6. Allow camera access and test movement detection.

## Testing
The application can be tested by:
- Starting the webcam.
- Enabling darkness simulation.
- Moving an object in front of the camera.
- Checking movement alerts.
- Verifying the detection history.

## Project Purpose
This project demonstrates real-time computer vision and movement monitoring through a web-based application.
